# ansurance

Custom CRM for a small Israeli insurance agency (5 agents, 2 back-office, 1 manager).

- Requirements: [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)

Highlights: a role-specific Inbox for Agent, Back-office and Manager; automatic digitizing, classification and portfolio attribution of incoming fax, email and WhatsApp (an ID scan goes straight to the folder of the ID's owner); real-time Hebrew/Arabic/Russian/French translation with subtitles, including phone calls; light and dark theme, language switcher, role switcher, "Show me" tour and a "Lens" for long lists.
